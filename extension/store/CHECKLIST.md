# 上架 Chrome 应用商店：要准备的东西

## 1. 开发者账号（你来办）
- 用一个 Google 账号注册 Chrome Web Store 开发者：<https://chrome.google.com/webstore/devconsole>，一次性付 **5 美元**注册费（要能付美元的信用卡）。
- 注册时会要求验证联系邮箱，并声明自己是不是「交易者」（trader，欧盟的规定）。个人开发、免费插件选**非交易者**即可。
- 发布者名称会公开显示在商店里，想好用什么名字。

## 2. 上传的包
- `node tools/build_ext.mjs --zip` 生成 `dist/bilifast-<版本>.zip`，就是 GitHub Release 里的那个 zip，直接上传。
- 每次更新都要把 `extension/manifest.json` 里的 `version` 调大，商店不接受同一个版本号。
- 代码不要压缩、混淆：审核时会看代码，`page.js` 是几个源文件直接拼起来的，保持可读。

## 3. 图片
| 图片 | 规格 | 状态 |
|---|---|---|
| 商店图标 | 128x128 PNG，图案 96x96、四周 16px 透明边 | ✅ `extension/icons/128.png`（`node tools/make_icons.mjs` 生成） |
| 小宣传图 | 440x280，JPEG 或不带透明通道的 PNG | ✅ `promo-440x280.jpg` |
| 截图 | 1280x800 或 640x400，1~5 张，JPEG 或不带透明通道的 PNG | ✅ 效果对比图 `screenshot-compare-1280x800.jpg`；**还要你自己截 1~2 张真实截图**，见下面 |
| 大宣传图 | 1400x560 | 可选，不做 |

### 要你自己截的截图
商店要求截图如实展示插件的样子，带工具栏图标和弹出页的截图只能在你自己的 Chrome 里截（自动化测试用的无头 Chrome 没有工具栏）。

**截图 1（必要）：视频页 + 弹出页**
1. 装好插件，打开一个 4K 视频（比如 BV1bE41127s6），画质选 4K，倍速开 2x，播放半分钟，等弹出页里「领先播放位置」到几十秒。
2. 点工具栏上的插件图标打开弹出页（能看到领先秒数、速度、节点、档位），同时让工具栏图标上的角标数字露出来。
3. 按 `Win + Shift + S` 截取整个浏览器窗口。
4. 用「画图」裁成 16:10（宽 ÷ 高 = 1.6），再「重新调整大小」到 1280x800 像素，另存为 PNG 或 JPEG。

**截图 2（可选）：番剧页或列表页**，步骤同上，说明插件在这些页面也能用。

截图前注意：
- 页面右上角的头像、用户名、消息数是你的个人信息，截图前点开头像菜单之外的地方，或者截完用马赛克盖住。
- 不要截到大会员专享、付费内容的标识，避免审核员误以为插件能绕过付费。
- 系统语言和 Chrome 界面是中文没关系。

## 5. 可能的审核问题
- **名称和商标**：名称里没有用「bilibili」「B 站」，说明里用到 B 站只是说明适用的网站，并写了「不是 B 站官方插件」。如果审核员仍然认为涉及商标，按要求改说明里的措辞即可，名称不用改。
- **接管 XMLHttpRequest**：审核员可能会问为什么要在页面里替换 `XMLHttpRequest`。回答：这是插件的唯一功能，只接管 B 站视频 CDN 上 `.m4s` 视频分段的 Range 请求，其他请求原样放行；出错时自动退回原请求。listing.md 里「主机权限的理由」已经写了。
- **和下载功能无关**：这个插件不提供下载，商店里也不要提下载（下载插件不上架，继续走 GitHub Release）。
- 审核一般几天到一两周。被拒时邮件里会写具体的政策条款，改了再提交。
