# bilifast

[中文](README.md) | [English](README.en.md) | **日本語**

**bilibili の Web プレーヤーで 4K・倍速再生・シークしても止まらなくする Chrome 拡張機能です。** 拡張機能を入れるだけで、Python などのプログラムは不要。データは一切収集しません。

<p align="center"><img src="docs/images/popup.png" alt="拡張機能のポップアップ：オン/オフ、低・中・高の 3 段階、現在のタブで再生位置より先に読み込んでいる秒数、速度、映像と音声に使っているノード、各ノードの実測速度" width="360"></p>

## インストール

1. [Releases](https://github.com/Yangxiamao/bilifast/releases/latest) から `bilifast-x.y.z.zip` をダウンロードします。
2. 決まったフォルダに展開します（あとで削除・移動しないでください）。
3. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにして「パッケージ化されていない拡張機能を読み込む」からそのフォルダを選びます。
4. bilibili の動画ページを再読み込みし、いつも通り視聴します。

Chrome ウェブストアに申請中です。公開後はストアから直接インストールできます。

**更新**：新しい zip を同じフォルダに上書き展開し、`chrome://extensions` で拡張機能の再読み込みボタンを押します。

## 効果

bilibili 純正プレーヤー、4K 固定、同じネットワーク・同じ動画での作者の実測（2026-10）：

| | 拡張機能なし | 拡張機能あり |
|---|---|---|
| 2 倍速で 30 秒 | 4 回停止、計 10.2 秒 | 停止なし |
| 60% にシークして 2 倍速 | ずっと止まったまま | 1 回、0.4 秒 |
| 3 倍速 | ずっと止まったまま | 停止なし |

仕組み：bilibili の動画 CDN はリクエストごとに速度を制限しており、プレーヤーは一度に 1 つしかリクエストを送りません。拡張機能はリクエストを小さく分割し、最も速い複数の bilibili ノードから並列に取得して先読みします。映像・弾幕・コメント・視聴履歴はすべて bilibili のものがそのまま使われます。もともと回線が十分速い場合は、違いをあまり感じないかもしれません。詳細（中国語）：[docs/PLAY_EXTENSION.md](docs/PLAY_EXTENSION.md)

## 使い方

- www.bilibili.com の動画ページ・リストページ・アニメ（番剧）ページに対応。パート切り替え、画質切り替え、連続再生も自動で引き継ぎます。
- ツールバーのアイコンの数字は、再生位置より何秒先まで読み込んでいるかです。「关」と表示されていれば高速化はオフです。
- アイコンをクリックすると高速化のオン/オフと、低・中・高の 3 段階を選べます（高いほど先読みが長く、メモリを多く使います）。通常は既定の「中」で十分です。

## プライバシー

要求する権限は `storage`（オン/オフと段階の保存用）だけです。Cookie は読まず、データの収集・送信も一切しません。問題が起きたときは直接接続に戻り、動画はそのまま再生されます。[PRIVACY.md](extension/store/PRIVACY.md)（中国語・英語）を参照してください。

Chrome 111 以上が必要です。他サイトに埋め込まれたプレーヤーとライブ配信は対象外です。大会員・有料コンテンツの制限は変わりません。

## 動画をダウンロードしたい場合

この拡張機能はオンライン再生を速くするだけで、動画のダウンロードはしません。mp4 で保存したい場合は、同じ作者の [bilidl](https://github.com/Yangxiamao/bilidl) を使ってください。2 つの拡張機能は同時に入れられます。

## 類似プロジェクト

[Bilibili 线程撕裂者](https://github.com/MrTangLuyao/Bilibili-thread-ripper)（ユーザースクリプト）も同じ考え方で、機能がより多く（8K、ドルビービジョン、ライブ配信、CDN のカスタマイズ）、中国大陸以外のユーザー向けに調整されています。bilifast は独自に実装した Chrome 拡張機能で、スクリプト管理ツールは不要、権限も 1 つだけです。
