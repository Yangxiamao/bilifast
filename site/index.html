B站卡顿、倍速转圈？
4K、2 倍速、拖进度不再卡

bilifast 是一个免费开源的 Chrome 插件。在B站（bilibili / 哔哩哔哩）网页上看视频时，它从多个B站视频节点同时拉取、提前预读，播放器就不会再因为缓冲不够而转圈。

从 Chrome 应用商店安装（免费） GitHub 源代码
  • 只装插件，不用装其他程序
  • 不收集任何数据
  • 开源（MIT）

实测：同一个 4K 视频，装与不装

B站自己的播放器，锁定 4K，同一网络、同一视频，按顺序 1 倍速 → 2 倍速 → 跳到 60% → 3 倍速。条越短越好。

作者 2026-10-29 实测：日本的家庭网络，登录账号，BV1bE41127s6（4K 2880×2160），Chrome 156，插件用默认的中档。不同网络、不同时间的结果会不一样；网络本来就很快的话，提升不明显。

为什么会卡，插件做了什么

B站的视频 CDN 对每个请求单独限速，而网页播放器一次只发一个请求。看 4K、高码率或者开倍速时，播放器需要的速度超过了一个请求能拿到的速度，缓冲用完就开始转圈。

不装插件

一次一个请求，跑不满你的网速。

装了 bilifast

拆成 1 MB 小块，从实测最快的几个节点同时拉取，提前预读约 90 秒，倍速时自动多读。

画面、弹幕、评论、清晰度切换、播放记录都还是B站自己的，用法和平时完全一样。插件出错时自动退回直连，视频照常播放。原理和开发经过写在这篇文章里：B站你对海外CDN限速是否搞错了什么；技术细节见 PLAY_EXTENSION.md。

怎么用

支持 www.bilibili.com 的视频页、列表页、番剧页，切换分 P、清晰度、自动连播都会自动接管。需要 Chrome 111 以上。

  1. 安装

    到 Chrome 应用商店点「添加至 Chrome」。商店版会自动更新。

  2. 刷新视频页

    打开或刷新B站视频页，照常看就行，不用做任何设置。

  3. 需要时调档位

    点工具栏图标可以开关加速、选低 / 中 / 高三档。图标上的数字是缓冲领先播放位置的秒数。

隐私

  • 只申请 storage 一个权限，用来在本机记住开关和档位。
  • 不读 cookie，不收集、不上传任何数据，没有统计和广告。
  • 只在B站的视频页、列表页、番剧页上运行。
  • 视频数据只在你的浏览器和B站的视频服务器之间传输。

完整说明见 隐私说明。代码全部开源，可以自己检查。

常见问题

为什么B站网页版看视频这么卡？

常见的原因是：B站视频 CDN 对每个请求单独限速，而网页播放器一次只发一个请求。4K、高码率、倍速播放需要的速度超过一个请求能拿到的速度，缓冲耗尽后就会转圈。你自己的网络慢、晚高峰拥堵也会卡，这种情况插件能帮的有限。作者正在录一期视频详细分析，做好后会放在这里。

安全吗？要哪些权限？

只申请 storage 一个权限，没有访问网站数据的权限。插件只在B站视频、列表、番剧页上运行，不加载远程代码，源代码在 GitHub 上公开。

会影响我的B站账号吗？

插件不读 cookie，不碰登录、评论、播放记录这些请求。它只是把播放器本来就要下载的视频分段，改成从B站自己的视频服务器分块并发下载，请求的是同样的视频地址。

支持 Edge 或其他浏览器吗？

目前只在 Chrome 111 以上测试过。Edge 等基于 Chromium 的浏览器可以从 Chrome 应用商店安装扩展，但作者还没有测试过；Firefox 和 Safari 不支持。

能下载B站视频吗？

不能，这个插件只加速在线播放。要把视频存成 mp4，可以用同作者的 bilidl，两个插件可以同时装。

直播、嵌入在其他网站的B站播放器能加速吗？

不能，只加速 www.bilibili.com 上的视频页、列表页和番剧页。

能看大会员或付费视频吗？

不能。大会员、付费内容的限制不变，本来看不了的视频装了插件也看不了。

网速本来就很快，还需要装吗？

提升可能不明显。可以先装上试试，不需要时在弹出页里随时关闭，关闭后和没装一样。
